## 🚀 Evident

**Live demo:** [evident-two.vercel.app](https://evident-two.vercel.app)

Evident helps small B2B SaaS companies answer enterprise security questionnaires in minutes instead of weeks. When a startup tries to close a deal with a large customer, the deal stalls at the security review — a spreadsheet with 200–500 questions. Evident centralizes approved answers, evidence, and a public trust page.

### What's inside
- Answer Library with immutable, versioned answers
- Evidence Vault with private, signed-URL storage
- Questionnaire auto-mapping using Postgres trigram similarity
- Public trust page for anonymous prospects
- Team management with role-based access control

### Stack
`Next.js 16` · `React 19` · `TypeScript` · `Supabase` · `Tailwind CSS v4` · `Framer Motion` · `Vercel`

### Architecture
- Multi-tenancy enforced with composite foreign keys
- Row Level Security on every table
- Immutable audit trail in a private schema
- SECURITY DEFINER RPCs to prevent privilege escalation
- Private storage with 300-second signed URLs
